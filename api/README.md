# 接口契约摘要

> 只列**路径 / 方法 / 用途 / 鉴权方式**，不含真实地址、示例值、字段取值与实现细节。
> 这些是作者设计的接口形状，公开它不影响安全（没有地址与凭据就调不通）。

## 1. 通知投递（对外，供其它系统调）

| 方法 | 路径 | 用途 | 鉴权 |
|---|---|---|---|
| POST | `/api/v1/push` | 向人/群投递一条通知（支持媒体） | API Key（请求头） |
| GET | `/api/v1/push/{id}` | 查询单次投递结果 | API Key |
| POST | `/api/v1/schedule` | 预约一条未来投递 | API Key |
| GET | `/api/v1/schedule/{id}` | 查询预约任务状态 | API Key |

## 2. 机器人回调（平台 → 本系统）

| 方法 | 路径 | 用途 | 鉴权 |
|---|---|---|---|
| POST | `/webhook/callback` | 平台事件回调（注册、关注/取关、消息） | 共享密钥（请求头） |
| POST | `/webhook/after` | 消息后置处理（自动回复、指令层） | 共享密钥 |

## 3. 教师侧收件（作用域受限）

| 方法 | 路径 | 用途 | 鉴权 |
|---|---|---|---|
| GET | `/api/v1/hw/roster` | 按时间窗/标签取收件名单与分母 | API Key + 作用域 |
| GET | `/api/v1/hw/list` | 列出某次作业的提交清单 | API Key + 作用域 |
| GET | `/api/v1/hw/export` | 批量打包下载提交物 | API Key + 作用域 |

作用域模型（`hw_scope_filter`）：一个 key 只能看自己名下的班级/标签范围，**越界即 403**，
不是在结果里过滤——先在查询层挡住。

## 4. 内部助手（前端 ↔ 助手服务）

| 方法 | 路径 | 用途 | 鉴权 |
|---|---|---|---|
| POST | `/chat` | 对话（流式返回） | 会话令牌 |
| GET | `/sessions` | 会话列表 | 会话令牌 |
| POST | `/chat/stop` | 中断生成 | 会话令牌 |

## 5. 管理控制台（内部）

| 方法 | 路径 | 用途 | 鉴权 |
|---|---|---|---|
| GET | `/api/accounts` | 账号列表与详情 | 控制台会话 |
| POST | `/api/bots` | 机器人增改 | 控制台会话 |
| GET | `/api/audit` | 操作审计 | 控制台会话 |
| GET | `/api/health` | 健康检查 | 控制台会话 |

## 约定

- 统一 JSON；错误体含 `code` / `message`（不返回堆栈）。
- 对外接口一律 API Key，**永不复用控制台高权凭据**；内部接口一律会话令牌，两者不互通。
- 所有写操作留审计流水（谁、何时、对谁、结果）。
