# 智能公众号

一套面向**校内**的即时通讯与通知系统：把「群发通知 / 作业收集 / 知识库问答 / 站点信息采集」
收在一个自托管平台上，给一个系的师生日常用。

本仓是它的**公开归属页**：只包含说明与架构概览，**不含任何代码、不含部署信息、
不含真实地址与账号**。代码与运行环境不在公开范围。

## 模块清单（只说做什么，不说怎么做）

- **即时通讯平台**：单人/群聊、消息类型（文本/图片/语音/文件/视频）、在线状态、已读回执
- **通知机器人**：关注/取关、单人推送、群发、媒体消息、对外 API（供其它系统投递通知）
- **定时推送**：预约发送、任务状态机、失败重试、群目标预检
- **管理控制台**：账号与标签、机器人、关注者、审计、健康检查、会话排查
- **教师侧接口**：作业收件、名单核对、批量打包导出（带作用域权限模型）
- **知识库问答**：文档入库、检索增强问答、引用清洗（接入开源 RAG 引擎）
- **自研 Web 前端**：官方前端之外的一套自研界面（移动端优先）
- **站点信息采集**：校内通知类页面的定时采集与摘要
- **算力平台**：内部模型服务的容量与调度

## 时间锚（本仓存在的主要理由）

本仓公开一个**不可反推的指纹**，用来把「谁先做的」从各说各话变成**可复算**的事实：

```
sha256 (对象图) = 2928935e8a89fb15339da937a8c1305165002b2ae24c40e2900043498f382e1c
```

口径：`git rev-list --all --objects | LC_ALL=C sort | sha256sum`；覆盖 322 个提交、
2337 个对象，最早提交 2026-08-10。推导命令原文与历史规模见 `ANCHOR.txt`。

**提交历史本身不公开**（离线 bundle + 时间戳凭证由作者保管）。指纹不可反推内容，
所以公开它不损害保密；而「给得出这个哈希」本身就是时间证据。
